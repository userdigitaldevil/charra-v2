# Whitelist of approved file-content SHA-256 hashes, one per line.
#
# Consulted by verify_log_r_file_hashes_against_policy() in src/verifier.c
# against the file-content digest preserved in each log_r entry by
# charra_sdk_redact_ima_log() (see src/core/charra_sdk.h). Default-deny: a
# digest that appears in neither this file nor blacklist-hashes.txt is
# treated as a failure, same as an explicit blacklist match.
#
# Format: "0x" followed by 64 hex characters (32 bytes), one hash per line.
# Blank lines and '#' comments are ignored.
#
# Empty by default -- every appraisal will fail the policy check until this
# is populated with the hashes of approved files.
